# Scheme Help Centre

Open `index.html` in a browser. No install or server needed.

## Add a new scheme
1. Copy a block in `data/schemes.js`, give it a unique `id`.
2. Add a matching entry in `data/rules.js` (yes / maybe conditions).

## Folders
- css/   styles (base, layout, components)
- js/    search, eligibility checking, rendering, page logic
- data/  schemes and eligibility rules
- assets/ images and icons (empty for now)
